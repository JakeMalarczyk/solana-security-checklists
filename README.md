# Solana security checklists

Free, printable checklists for Solana teams, written by [Orivions](https://orivions.com), a marketplace where onchain teams find service providers that a person has checked first.

| Checklist | Checks | Use it when |
|---|---|---|
| [Pre-launch security](checklists/pre-launch-security.md) | 15 | You are preparing a mainnet launch: keys, deployment and operations |
| [Anchor security](checklists/anchor-security.md) | 16 | Your Anchor program is about to go to an auditor |
| [Audit readiness](checklists/audit-readiness.md) | 12 | You are booking an audit and want the review time to count |

## How to use them

1. Copy a checklist into your project tracker and assign a name to every line.
2. Work through it before you send code to an auditor or deploy to mainnet.
3. Keep the filled-in list with your audit report.

These lists prepare you for an audit. They do not replace one.
